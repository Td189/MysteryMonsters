# MysteryMonsters
Welcome to Mystery Monsters!
There are quite a few aspects of this program that you should be aware of before you get started. 
1. You can identify the controls in the terminal after initiating the program. 
2. Pressing B will trigger a wild battle.
3. The main game is simply an open area, there is a special pink tile that you can use to heal your monsters whenever they become weakened.
4. Pressing the O key while running the program will make use of some data structure functions.
5. Have fun and thank you for using this program!
